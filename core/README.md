# braintax4rust-core

The analysis behind [`cargo-braintax4rust`](https://crates.io/crates/cargo-braintax4rust):
the cognitive tax of Rust code. This crate is the counting, the scoring and the
text report; the command, `cargo braintax4rust`, is the `cargo-braintax4rust`
crate.

What it measures, the formula and how to read a report are in the
[main README](https://github.com/umbgtt10/braintax4rust#readme) and
[`docs/FORMULA.md`](https://github.com/umbgtt10/braintax4rust/blob/main/docs/FORMULA.md).
